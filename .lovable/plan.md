#### סקציית הורדת סילבוס חדשה

עיצוב מוצע:
```
┌─────────────────────────────────────────────────────────────┐
│                     רקע Warm Cream                          │
│                                                              │
│              📄 רוצה לדעת בדיוק מה תלמדי?                   │
│                                                              │
│     הורידי את הסילבוס המלא של התוכנית וגלי את כל            │
│     התכנים, המפגשים והבונוסים שמחכים לך                     │
│                                                              │
│            ┌──────────────────────────────┐                  │
│            │  📥 הורדת סילבוס התוכנית    │  ← כפתור Gold    │
│            └──────────────────────────────┘                  │
│                                                              │
│              או התקשרי אלינו: 050-XXXXXXX                    │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**פיצ'רים:**
- אייקון `FileDown` או `Download`
- כותרת Heebo Bold
- תיאור קצר ב-Assistant
- כפתור Gold להורדה
- אופציה ליצירת קשר (טלפון/וואטסאפ)
- אנימציית כניסה עם framer-motion

**הערה טכנית:**
הכפתור יפתח קובץ PDF בטאב חדש. נצטרך להעלות את קובץ הסילבוס ל-public folder או להשתמש בלינק חיצוני.
