

# פריסה מומלצת: וידאו דומיננטי + טאבים למטה

## הרציונל

מאחר שהשקפים הם תומכי למידה ולא תוכן עצמאי, אין צורך להציג אותם במקביל לוידאו באופן קבוע. הוידאו צריך לקבל את מרבית המסך, והשקפים וההערות יהיו נגישים בטאב מתחת - כך הסטודנט יכול להציץ בהם כשצריך.

## הפריסה המוצעת

```text
+--------------------------------------------------+
|  סרגל ניווט (חצים + מספר שיעור)                    |
+--------------------------------------------------+
|                                                    |
|              וידאו (רוחב מלא)                       |
|                                                    |
+--------------------------------------------------+
|  כותרת השיעור + מספר שיעור                         |
+--------------------------------------------------+
| [הערות אישיות] | [שקפים] | [קבצים] | [סקירה]      |
+--------------------------------------------------+
|                                                    |
|           תוכן הטאב הנבחר                          |
|                                                    |
+--------------------------------------------------+
```

## למה זה עדיף

- **וידאו ברוחב מלא** - חוויית צפייה טובה יותר, במיוחד כשהוידאו הוא התוכן העיקרי
- **שקפים בטאב** - נגישים בלחיצה אחת, לא תופסים מקום קבוע על המסך
- **הערות כטאב ראשון (ברירת מחדל)** - הסטודנט רואה אותן מיד, יכול לכתוב תוך כדי צפייה
- **ממשק נקי** - מתאים לפילוסופיית "distraction-free" של הפורטל
- **עובד טוב במובייל** - אותה פריסה בדיוק, ללא צורך בהתאמה

## שינויים טכניים

### קובץ: `src/pages/LessonDetail.tsx`

1. **הסרת הפיצול 60/40** - הוידאו יעבור לרוחב מלא
2. **העברת המצגת לתוך הטאבים** - טאב "שקפים" חדש עם רכיב `PresentationViewer`
3. **העברת ההערות לטאב ראשון** - `LessonNotes` יהיה בטאב במקום מתחת
4. **סדר הטאבים**: הערות אישיות (ברירת מחדל) | שקפים | קבצים מצורפים | סקירה ושאלות

### שינויי טאבים

| טאב | תוכן | אייקון |
|-----|-------|--------|
| הערות אישיות (ברירת מחדל) | `LessonNotes` | StickyNote |
| שקפים | `PresentationViewer` בגובה קבוע | Presentation |
| קבצים מצורפים | רשימת קבצים קיימת | FileText |
| סקירה | תיאור השיעור + שאלות ותשובות | Info |

### קבצים לעדכון

| קובץ | שינוי |
|------|-------|
