

# סנכרון הצגת טקסט עם קול (Voice-Synced Text)

## מה ישתנה
כשהקול מופעל (שלב הסימולציה בגשר הקשר), הטקסט לא יופיע בזמן הסטרימינג. במקום זה:
1. בזמן שהטקסט מגיע מהשרת - יוצג רק אינדיקטור טעינה ("מכין תשובה...")
2. במקביל, כל האודיו ייאסף מ-ElevenLabs
3. כשהאודיו מוכן ומתחיל לנגן - הטקסט יתחיל להופיע תו-אחרי-תו בקצב מסונכרן עם משך האודיו

## פרטים טכניים

### 1. קובץ: `src/hooks/useTTS.ts`
- תיקון הבאג שהקול נחתך: איסוף כל ה-chunks לפני ניגון (הסרת לוגיקת 8KB)
- חשיפת `duration` (משך האודיו בשניות) דרך ה-hook
- חשיפת callback `onPlayStart` כדי שה-ChatMessage ידע מתי הניגון התחיל בפועל

ממשק מעודכן:
```text
interface TTSControls {
  speak: (text: string) => void;
  stop: () => void;
  isPlaying: boolean;
  isLoading: boolean;
  isSupported: boolean;
  duration: number | null;  // חדש - משך האודיו בשניות
}
```

### 2. קובץ: `src/components/bots/ChatMessage.tsx`
- כאשר `enableVoice && isLatestAssistant` ויש סטרימינג פעיל:
  - הטקסט מוסתר, מוצג רק אינדיקטור טעינה
  - ה-TTS מופעל ברגע שהסטרימינג נגמר (כמו היום)
- כאשר ה-TTS מתחיל לנגן:
  - חישוב קצב הקלדה: `duration * 1000 / content.length` (מילישניות לתו)
  - הטקסט מופיע תו-אחרי-תו בקצב הזה
- כאשר הקול נעצר או מסתיים: כל הטקסט מוצג מיד
- הודעות ישנות (לא latest) ממשיכות להופיע רגיל ללא סנכרון

### זרימת האירועים:

```text
משתמש שולח הודעה
    |
    v
סטרימינג מתחיל --> מוצג "..." או Loader (טקסט מוסתר)
    |
    v
סטרימינג נגמר --> TTS מתחיל להיטען מ-ElevenLabs
    |
    v
אודיו מוכן --> ניגון מתחיל + טקסט מופיע בסנכרון
    |
    v
אודיו נגמר --> כל הטקסט מוצג
```

### שינויים בקבצים:
- `src/hooks/useTTS.ts` - איסוף כל הנתונים, חשיפת duration
- `src/components/bots/ChatMessage.tsx` - לוגיקת סנכרון טקסט-קול
